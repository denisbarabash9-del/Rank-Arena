RANK ARENA v2 — НАСТОЯЩЕЕ ПРИЛОЖЕНИЕ ДЛЯ iPHONE
===================================================

ЧТО ВНУТРИ
- Готовый Xcode-проект для iOS: RankArena.xcodeproj
- Встроенная игра v2 (9 героев, драфт 3×3, разные атаки и более слабые боты)
- Горизонтальная ориентация, режим на весь экран, без адресной строки
- Иконка игры и автономный запуск без интернет-соединения
- GitHub Actions: автоматическая сборка НЕПОДПИСАННОГО .ipa на сервере macOS

ВАЖНО: Это исходный проект приложения, НЕ готовый установочный .ipa.
В текущем окружении нет macOS, Xcode, а также вашего сертификата Apple,
поэтому создать и подписать готовый для установки .ipa здесь нельзя.

ВАРИАНТ 1 — ЕСТЬ MAC
1. Распакуйте архив, откройте RankArena.xcodeproj в Xcode.
2. Подключите iPhone через кабель к Mac; на телефоне подтвердите доверие.
3. В Xcode выберите проект RankArena → Signing & Capabilities.
4. Выберите свою Team (Apple Account / Personal Team).
5. При необходимости поменяйте Bundle Identifier на уникальный.
6. В списке устройств Xcode выберите свой iPhone, нажмите Run (▶).
7. Если попросят, включите Режим разработчика на iPhone.

ВАРИАНТ 2 — ТОЛЬКО WINDOWS, БЕЗ MAC
1. Создайте пустой репозиторий GitHub и загрузите ВСЕ файлы из этого архива,
   включая скрытую папку .github/workflows (её видно, если включить скрытые файлы).
2. GitHub → Actions → «Собрать IPA (без подписи)» → Run workflow.
3. После успешной сборки скачайте артефакт RankArena-unsigned-ipa.
4. Распакуйте его — внутри будет НЕПОДПИСАННЫЙ RankArena-unsigned.ipa.
5. Чтобы поставить приложение на обычный iPhone, подпишите и установите
   этот .ipa с помощью Sideloadly/AltStore с вашим Apple Account.
   Это отдельный этап, он может не сработать из-за ограничений Apple.
6. С бесплатной подписью обычно требуется переустанавливать/обновлять
   приложение раз в 7 дней.

ПРИМЕЧАНИЕ:
- Через «Файлы» на iPhone ZIP или .ipa напрямую НЕ устанавливается.
- Эта сборка — нативная оболочка на WKWebView со встроенной HTML-игрой,
  а НЕ переписанная на Swift игра и НЕ приложение из App Store.
- Внутри нет трекеров и сторонних SDK. Статистика ранга хранится локально.
- Из-за отсутствия Xcode здесь iOS-компиляцию и запуск на устройстве
  проверить пока невозможно.
